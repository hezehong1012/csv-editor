オンラインCSVエディタ ― 完全無料・ブラウザ完結・データ送信なし

CSV / TSV / Excel をドラッグ＆ドロップで開いて、その場で編集。日付変換・ランダムデータ生成（マイナンバー・SSN・電話番号）にも対応。データは一切サーバーにアップロードされません。

100% クライアント処理登録不要無料

主な機能

ブラウザ完結の編集

セルをクリックしてその場で編集。行・列の追加/削除、ヘッダー変更、並べ替え、絞り込み、検索に対応。

充実の入力対応

ドラッグ＆ドロップ、クリック選択、テキスト貼り付け、サンプル読み込み。Excel(.xlsx) の複数シートにも対応。

文字コード/区切りの自動判別

Shift-JIS / EUC-JP / UTF-8 BOM など日本語 Excel でありがちな文字化けを解消。区切り文字も自動判別。

リージョン対応ランダム生成

マイナンバー（検査数字付き）、米国SSN、英国NINo、各国の電話番号、パターン付きランダム日付を生成。

多形式で書き出し

Excel(.xlsx)、CSV（エンコーディング/区切り/改行選択可）、TSV、JSON、JSON Lines をワンクリックでダウンロード。

プライバシー最優先

ファイルはサーバーに送られず、すべて手元のブラウザで処理。機密データも安心して扱えます。

使い方（3ステップ）

  1. CSV / TSV / Excel をドラッグ＆ドロップ、または「サンプルデータを読み込む」で開きます。必要に応じて文字コードと区切り文字を選択。
  2. セルをクリックして編集したり、「データを生成・処理する」パネルで日付変換やランダムデータ列を追加します。
  3. 「書き出す」パネルから Excel / CSV / TSV / JSON など任意の形式でダウンロード。ファイルは手元に保存されます。

よくある質問

CSVをサーバーに送信せずに編集できますか？
はい。当ツールはすべてブラウザ内で処理され、ファイルはサーバーにアップロードされません。登録やログインも不要です。
対応しているファイル形式は？
CSV、TSV、テキスト、Excel(.xlsx)の読み込みに対応。書き出しは Excel、CSV（UTF-8/Shift-JIS/EUC-JP）、TSV、JSON、JSON Lines から選べます。
文字化けせずに開けますか？
UTF-8 / UTF-8 BOM / Shift-JIS / EUC-JP / Windows-1252 などの文字コード、カンマ/タブ/セミコロンなどの区切り文字を自動判別し、手動でも切り替えられます。
マイナンバーやSSNなどのランダム生成はできますか？
日本のマイナンバー（12桁・チェックデジット付き）、米国SSN、英国NINo、日本/米国/英国の電話番号、ランダム日付の生成に対応しています。
大きなCSVでも動きますか？
ブラウザのメモリの範囲内で動作します。ページネーション表示で1万行程度でも快適に閲覧・編集できます。
